# Trivia CLI Game 🧠

A Command-Line Interface (CLI) trivia game built with JavaScript. This project was developed as a Summative Lab to demonstrate foundational JavaScript concepts, including asynchronous timers, array iteration, and user input handling.

## 📋 Features

- **Interactive Gameplay:** Start the game and answer questions directly in your terminal.
- **Immediate Feedback:** Get instant feedback on whether your answer is correct or incorrect.
- **Timer:** A built-in timer limits the duration of the game to keep the challenge engaging.
- **Score Tracking:** Tracks your score and displays your final results at the end of the game.
- **Array Iteration:** Utilizes JavaScript array methods (like `.map()` or `.forEach()`) to manage the question bank.

## 🛠️ Technologies Used

- **JavaScript (Node.js):** Core logic and functionality.
- **Readline Module:** Used to handle user input in the CLI.
- **Git/GitHub:** Version control and repository hosting.
